# SQL Database Refactoring | Refactorizarea Bazei de Date SQL

## EN
**Status:** In Progress 🛠️
This project focuses on the redesign and optimization of a relational database. It aims to demonstrate normalization techniques (1NF to 3NF) and query optimization using Oracle SQL.
